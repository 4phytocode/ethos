[**Major design changes**]
Instead of this modern, sleek minimalist and professional feel. We will
use this idea, but it will be more retro, more vintage and more boxy. Just
like the ethos website presents. Think, matrix, early 2000s, 90's feel.
Windows 98.

Reference images are included in this folder.
Icons, symbols and other text (IBM Plex fonts, Vintage fonts) will be
used instead of the traditional, productivity feel to it.

We want a pixelated feel, a more retro, vintage looking feel to the entire
system. It's like, everything that windows 98, windows xp used to feel like, except the fact that it has a modern-fast paced, efficient system. 

The software needs to feel highly interactable, almost as if the 
entire software itself is "alive". Fluid button mechanics, fluid
systems of typing, typing sounds as-well (?) in the journal and 
note system, along with an option to toggle it on or off.
